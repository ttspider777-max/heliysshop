# heliys shop bot

Бот-магазин физических номеров и AI-сервисов на aiogram 3.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Админ-панель: команда `/admin` или кнопка «⚙️ Админ-панель» в главном меню (видна только админам из `config.py`).

## Как добавить товар

1. Админ-панель → ➕ Добавить товар → категория → название → описание → цена → тип выдачи:
   - **Автовыдача** — бот сам выдаёт номера/аккаунты со склада;
   - **Ручная выдача** — после оплаты админу приходит кнопка «✉️ Выдать товар».
2. 📦 Добавить аккаунты → выбрать товар → отправить список (одна строка = один товар) или .txt файл.
   Всем, кто нажал «Уведомить о поступлении», бот сразу напишет.

## Премиум-эмодзи

- В тексте (приветствие, описания, рассылка, реквизиты) — просто вставьте их в сообщение.
- В кнопках — ✏️ Оформление → 🔘 Кнопки → кнопка → «💎 Премиум-эмодзи» (или поставьте эмодзи в начало текста кнопки).
- Отображаются, только если у владельца бота есть Telegram Premium.

## Данные

SQLite: локально `data/heliys_shop.db`, на Amvera — `/data/heliys_shop.db`.

## Покупка нескольких штук

Админ-панель → 📁 Категории → категория → «🔢 Несколько штук». В такой категории покупатель после «Купить» выбирает
количество (−10 / −1 / +1 / +10 или вводит число), итог считается автоматически. Для автовыдачи максимум — остаток на складе,
для ручной — 10 000 шт. Много позиций (не влезают в сообщение) отправляются .txt файлом.

## Премиум-эмодзи в названии товара

Вставьте премиум-эмодзи в название товара (при создании или через ✏️ Название) — оно станет иконкой кнопки товара
в списке и покажется в карточке товара.

## Обязательная подписка

Админ-панель → 📣 Обязательная подписка → ➕ Добавить канал (бот должен быть админом канала).
Канал можно указать как @username, ссылкой, ID или переслать пост из него. Можно добавить несколько каналов,
удалить любой или временно выключить проверку. Админы бота подписываться не обязаны.

## Деплой (GitHub / BotHost)

Токен в коде не хранится. На хостинге задайте переменную окружения `BOT_TOKEN`
(или создайте файл `.env` по образцу `.env.example`). Точка входа — `main.py`, зависимости — `requirements.txt`.
Админы, ссылки и реквизиты по умолчанию лежат в `config.py`, остальное меняется в админ-панели.

## Внешние магазины (перепродажа по API)

Админ-панель → 🔌 Внешние магазины (API) → ➕ Подключить магазин: название, адрес API, ключ и наценка в %.
Бот загрузит товары магазина в отдельную категорию «🔌 Название» с вашей наценкой. Покупатель платит вам как за
обычный товар, а бот сам заказывает товар у магазина-поставщика по API и выдаёт его. Если поставщик не смог выдать
товар (нет остатка, не хватило средств на его балансе, ошибка сети) — деньги сразу возвращаются покупателю на баланс,
а вам приходит сообщение с причиной. Остатки и цены обновляются автоматически раз в 10 минут (и кнопкой 🔄).

У каждого магазина API свой, поэтому в «⚙️ Расширенные настройки API» можно поменять: способ авторизации (Bearer /
заголовок / параметр в URL), пути методов «список» и «покупка», метод (GET/POST) и шаблон тела покупки
(`{"product_id": "$id", "quantity": "$qty"}`, где `$id` и `$qty` подставляются сами). Ответы разбираются автоматически:
список товаров ищется в корне или в `data / products / items / result`, поля — `id`, `name|title`, `price|cost`,
`stock|count|quantity`; выданный товар — в `items / accounts / data / content`. Кнопка «🧪 Проверить» показывает, что бот
увидел в ответе.

## Документы и подключение оплаты

Админ-панель → 📄 Документы (оплата): политика конфиденциальности и пользовательское соглашение. Можно отправить текст
сообщением или .txt файлом, либо вставить готовый шаблон и поправить места «[УКАЖИТЕ: …]». Тексты меняются в любой момент.
Они доступны покупателям в меню «📄 Документы», командами /terms и /privacy и кнопками при оформлении заказа.

Для платёжной системы бот публикует страницы `/privacy` и `/terms` (порт 80 на Amvera, локально 8080; меняется
переменной `PORT`). Укажите адрес сайта бота (например `https://ваш-проект.amvera.io`) кнопкой «🌐 Адрес сайта» — в админке
появятся готовые ссылки. Если домена нет, у документа можно указать свою ссылку (например, на Telegraph).
«🏢 Реквизиты продавца» выводятся под документами и на сайте. «Требовать согласие при входе» просит каждого покупателя
нажать «Принимаю» перед использованием бота.

## Скрытие кнопок и «Поставщики»

- Админ-панель → 🙈 Скрыть кнопки: список всех кнопок бота по разделам — нажмите, чтобы убрать (🙈) или вернуть (✅).
  Скрыть оба способа оплаты одновременно нельзя.

- Админ-панель → ✏️ Оформление → 🔘 Кнопки → любая кнопка главного меню → «🙈 Убрать из главного меню» (и обратно «👁 Показать»). Скрытые кнопки помечены 🙈 в списке.
- В главном меню есть кнопка «🏭 Поставщики». Поставщиков добавляет админ: Админ-панель → 🏭 Поставщики → ➕ Добавить поставщика (название, описание, цена, способ выдачи — как у товара). Покупатели видят их по этой кнопке и покупают как обычный товар. В общий каталог, хиты, новинки и поиск поставщики не попадают.

## Просмотр содержимого товара

Админ-панель → 🗂 Товары → товар → «👁 Содержимое товара»: показывает текст товара (описание) и всё, что лежит на складе
(по 8 штук на страницу, с остатком и числом проданных). Кнопка «📄 Скачать всё .txt» присылает склад файлом.

## Бесконечный товар и размножение

Админ-панель → 📦 Пополнить склад → товар → отправьте **одну** позицию (юзернейм, ссылку). Бот спросит:
- **➕ Добавить 1 шт.** — как обычно;
- **🔢 Размножить** — введите число (до 10 000), позиция добавится на склад столько раз;
- **♾ Бесконечно** — каждый покупатель получает эту позицию, склад не заканчивается.
  Выключить — в карточке товара «⛔ Выключить бесконечность» (или «🗑 Очистить склад»).
Если отправить несколько строк — они добавятся сразу, как раньше.

## Админы

Админ-панель → 👮 Админы: добавить по ID, @username или пересланному сообщению, удалить.
Управляют списком только владельцы — ID из `ADMINS` в `config.py`.
