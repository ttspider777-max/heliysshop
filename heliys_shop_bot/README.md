# heliys shop bot

Бот-магазин физических номеров и AI-сервисов на aiogram 3.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Админ-панель: команда `/admin` или кнопка «⚙️ Админ-панель» в главном меню (видна только админам из `config.py`).

## Как добавить товар

1. Админ-панель → ➕ Добавить товар → категория → название → описание → цена → тип выдачи:
   - **Автовыдача** — бот сам выдаёт номера/аккаунты со склада;
   - **Ручная выдача** — после оплаты админу приходит кнопка «✉️ Выдать товар».
2. 📦 Добавить аккаунты → выбрать товар → отправить список (одна строка = один товар) или .txt файл.
   Всем, кто нажал «Уведомить о поступлении», бот сразу напишет.

## Премиум-эмодзи

- В тексте (приветствие, описания, рассылка, реквизиты) — просто вставьте их в сообщение.
- В кнопках — ✏️ Оформление → 🔘 Кнопки → кнопка → «💎 Премиум-эмодзи» (или поставьте эмодзи в начало текста кнопки).
- Отображаются, только если у владельца бота есть Telegram Premium.

## Данные

SQLite: локально `data/heliys_shop.db`, на Amvera — `/data/heliys_shop.db`.

## Покупка нескольких штук

Админ-панель → 📁 Категории → категория → «🔢 Несколько штук». В такой категории покупатель после «Купить» выбирает
количество (−10 / −1 / +1 / +10 или вводит число), итог считается автоматически. Для автовыдачи максимум — остаток на складе,
для ручной — 100 шт. Много позиций (не влезают в сообщение) отправляются .txt файлом.

## Премиум-эмодзи в названии товара

Вставьте премиум-эмодзи в название товара (при создании или через ✏️ Название) — оно станет иконкой кнопки товара
в списке и покажется в карточке товара.

## Обязательная подписка

Админ-панель → 📣 Обязательная подписка → ➕ Добавить канал (бот должен быть админом канала).
Канал можно указать как @username, ссылкой, ID или переслать пост из него. Можно добавить несколько каналов,
удалить любой или временно выключить проверку. Админы бота подписываться не обязаны.

## Деплой (GitHub / BotHost)

Токен в коде не хранится. На хостинге задайте переменную окружения `BOT_TOKEN`
(или создайте файл `.env` по образцу `.env.example`). Точка входа — `main.py`, зависимости — `requirements.txt`.
Админы, ссылки и реквизиты по умолчанию лежат в `config.py`, остальное меняется в админ-панели.

## Скрытие кнопок и «Поставщики»

- Админ-панель → ✏️ Оформление → 🔘 Кнопки → любая кнопка главного меню → «🙈 Убрать из главного меню» (и обратно «👁 Показать»). Скрытые кнопки помечены 🙈 в списке.
- В главном меню есть кнопка «🏭 Поставщики». Поставщиков добавляет админ: Админ-панель → 🏭 Поставщики → ➕ Добавить поставщика (название, описание, цена, способ выдачи — как у товара). Покупатели видят их по этой кнопке и покупают как обычный товар. В общий каталог, хиты, новинки и поиск поставщики не попадают.
